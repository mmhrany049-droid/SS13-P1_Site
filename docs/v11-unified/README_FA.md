# SS 11 یکپارچه

در نسخه ۱۱، از دید کاربر فقط **یک سایت SS** وجود دارد. همه کاربران از همان صفحه ورود وارد می‌شوند و تفاوت دسترسی فقط از روی حساب، نقش و رمز عبور تعیین می‌شود.

## ورود واحد

- یک ایمیل یا شماره موبایل
- یک رمز عبور
- یک حساب می‌تواند چند نقش و چند عضویت داشته باشد
- دانش‌آموز پس از ورود فقط تجربه SS را می‌بیند
- معلم، آموزشگاه، مدرسه و رئیس پس از ورود داشبورد مربوط به نقش خود را می‌بینند
- اگر یک نفر چند نقش داشته باشد، پس از ورود یک انتخاب‌گر نقش کوتاه نمایش داده می‌شود
- هیچ آدرس عمومی با نام admin یا student به کاربر نشان داده نمی‌شود

## اصل مهم

نقش، مسیر ورود نیست. نقش یک مجوز روی همان حساب است. بنابراین «رمز دیگر» نباید به‌تنهایی مجوز بسازد؛ سرور باید نقش ثبت‌شده، سازمان، وضعیت حساب و اشتراک را هم بررسی کند.

## داده‌های نسخه‌های قبلی

کد و داده‌های قبلی برای حفظ قابلیت‌های موجود در پوشه‌های `student/` و `admin/` نگه داشته شده‌اند و هسته رسمی در `packages/core/` قرار دارد. لایه یکپارچه باید این دو پوسته را به یک route tree و یک session تبدیل کند.
