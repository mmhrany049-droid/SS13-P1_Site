# SS 11 نقش‌ها و دسترسی

## اصل محصول
یک حساب کاربری، چند عضویت سازمانی، و دو پوسته: SS برای دانش‌آموز و مدیریت برای نقش‌های حرفه‌ای. مجوزها باید در API enforce شوند، نه فقط با مخفی‌کردن منو.

| نقش | پوسته | دامنه |
|---|---|---|
| دانش‌آموز | SS | داده شخصی، برنامه، مرور، آزمون‌های اختصاص‌یافته |
| معلم مستقل | مدیریت | دروس و کلاس‌های خودش، کتاب‌های درس خودش، آزمون و ویدئو |
| معلم آموزشگاه | مدیریت | امکانات معلم در آموزشگاه‌های عضو |
| ادمین معلم | مدیریت | تیم معلم و محتوای دامنه مربوط |
| ادمین آموزشگاه | مدیریت | سازمان، کلاس، ثبت‌نام، گزارش و اشتراک آموزشگاه |
| رئیس | مدیریت | چند سازمان، مالی، اشتراک و گزارش کلان |
| ادمین رئیس | مدیریت | مدیریت کاربران و تنظیمات حساس رئیس |

مدرسه و آموزشگاه دو نوع سازمان مستقل هستند. عضویت معلم در سازمان رابطه است و هویت مستقل او را از بین نمی‌برد.
