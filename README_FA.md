# SS ۱۳ — نسخهٔ «سایت» (آمادهٔ انتشار روی یک دامنه)

یک دامنه، دو در: دانش‌آموز به «کابین مطالعه» (`/today`) و کارکنان به «میز کار» (`/workspace`) با یک ورود. بازدیدکنندهٔ بدون ورود صفحه‌های عمومی `/`، `/features`، `/pace`، `/privacy`، `/terms`، `/contact` را می‌بیند.

## حساب مدیر کل برنامه
در `data/` از قبل ساخته شده؛ نقش‌ها: **مالک + ادمین سیستم + دانش‌آموز** (نقش سوم فقط برای این است که با همین حساب نسخهٔ دانش‌آموزی را هم ببینی؛ بعد از ورود نقش را انتخاب می‌کنی).
- نام کاربری (ایمیل ورود): `ss.admin@ss-site.ir`
- رمز اولیه: در پیام تحویل آمده (در این بسته نیست؛ فقط هش آن در `data/` است).
- ورود دومرحله‌ای (Authenticator/Aegis) برای نقش‌های مالک و ادمین اجباری است؛ رمز را همان روز عوض کن.
- ساخت دوبارهٔ حساب با رمز دلخواه: `SS_SUPERADMIN_PASSWORD='رمز-دست‌کم-۱۲-نویسه' SS_SUPERADMIN_EMAIL='you@your-domain.ir' npm run superadmin`

## راه‌اندازی — فقط ۲ مقدار در `.env` را عوض کن
`.env` آماده است (HTTPS، پروکسی و ورود دومرحله‌ای روشن). این دو خط را ویرایش کن:
```
SS_DOMAIN=دامنهٔ-تو.ir
SS_CONTACT_EMAIL=ایمیل-پشتیبانی-تو
```
رکورد A دامنه را به IP سرور بزن، بعد **یکی** از این‌ها:

**الف) Docker (یک دستور؛ Caddy و گواهی HTTPS خودکار):**
```
docker compose up -d
```
**ب) بدون Docker (Node ≥ ۲۲٫۵):** پوشه را در `/opt/ss` بگذار.
```
npm start                                          # خود برنامه روی پورت ۸۰۸۰
export $(grep -v '^#' .env | xargs) && caddy run --config deploy/Caddyfile   # HTTPS روی دامنه
```
برای اجرای دائمی از `deploy/ss.service` (systemd) استفاده کن؛ اگر nginx داری `deploy/nginx.conf` هست.

**آزمایش روی کامپیوتر خودت:** `npm start` و باز کردن `http://localhost:8080` (در `.env` برای این حالت `SS_COOKIE_SECURE=0` بگذار اگر مرورگرت Safari است).

## بعد از اولین اجرا
- پوشهٔ `data/` همهٔ اطلاعات است: پشتیبان منظم بگیر، در مخزن عمومی نگذار.
- متن «حریم خصوصی» و «شرایط» پیش‌نویس است و پیش از عرضه به نوجوانان باید حقوقدان نهایی کند؛ شمارهٔ‌های کمک در `safetyLexicon.fa.json` هنوز «تأییدنشده» علامت دارند.
- نیمهٔ دانش‌آموزی برای کاربران واقعی: از «افراد و نقش‌ها» در میز کار حساب دانش‌آموز بساز (رمز موقت یک‌بار نمایش داده می‌شود).
- استقرار روی سرور واقعی و Docker/Caddy را من اجرا نکرده‌ام؛ فقط خود برنامه از بستهٔ zip بالا آمده و آزموده شده. فهرست ناتمام‌ها: `docs/V13_CHANGES_FA.md`.
